🚀 PROCEDIMENTO DE ATUALIZAÇÃO (PASSO A PASSO):

  $ cd /www/wwwroot
  $ mv erp-grafica erp-grafica-backup-v2.5.0
  $ unzip print-shop-erp-v2.5.1.zip
  $ cd erp-grafica

  $ npm install --legacy-peer-deps
  $ psql -U postgres -d app_db -f create-tables.sql
  $ npm run build
  $ pm2 restart erp-grafica

✅ TESTES PÓS-ATUALIZAÇÃO:

  1. Verificar banco de dados:
     $ psql -U postgres -d app_db -c "SELECT COUNT(*) FROM users;"
     └─ Esperado: tabela existe (mesmo que vazia)

  2. Testar API:
     $ curl http://localhost:3000/api/whatsapp
     └─ Esperado: JSON com config, templates, socketInfo

  3. Gerar QR code:
     $ curl -X POST http://localhost:3000/api/whatsapp \
       -H "Content-Type: application/json" \
       -d '{"action":"generate_qr"}'
     └─ Esperado: JSON com qrCodeUrl (data:image/png;base64,...)

  4. Acessar página visual:
     $ curl http://localhost:3000/qr-code
     └─ Esperado: HTML com página de conexão WhatsApp
